# Web Fonts Directory (`assets/fonts/`)

Place self-hosted WOFF2 font files here for offline production deployment:
- `IBMPlexSans-Regular.woff2` (400)
- `IBMPlexSans-Medium.woff2` (500)
- `IBMPlexSans-SemiBold.woff2` (600)
- `IBMPlexSansArabic-Regular.woff2` (400)
- `IBMPlexSansArabic-Medium.woff2` (500)
- `IBMPlexMono-Regular.woff2` (400)

In `index.html`, Google Fonts CDN for `IBM Plex Sans`, `IBM Plex Sans Arabic`, and `IBM Plex Mono` is linked with graceful fallback to system grotesque/Arabic sans-serif stacks declared in `assets/css/base/variables.css`.
